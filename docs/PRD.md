# PRD — MediMate 기획서 & 요구사항

## 1. 배경 및 문제 정의

약을 복용하는 사람의 50% 이상이 복용을 빠뜨리거나 용량을 잘못 지킨다는 연구가 있다.
현재 시중의 약 관리 앱은 사용자가 직접 약 이름·용량·시간을 일일이 입력해야 해서 초기 설정이 번거롭다.

**핵심 페인포인트:**
- 약 포장지 정보를 앱에 수동 입력하는 번거로움
- 복용 시간을 잊어버리는 문제
- 여러 약을 동시에 복용할 때 상호작용·주의사항 파악 어려움

## 2. 목표

카메라로 약을 찍는 것만으로 복용 스케줄이 자동 생성되는 앱을 만든다.

## 3. 타겟 사용자

| 세그먼트 | 특징 |
|----------|------|
| 1차 타겟 | 처방약을 2종 이상 복용하는 만성질환자 (40~70대) |
| 2차 타겟 | 감기약·영양제 등 단기 복용 관리가 필요한 일반인 |

## 4. 핵심 기능 요구사항 (MVP)

### F-01. 약 스캔 & AI 인식
- 카메라 또는 갤러리에서 약 포장지 이미지를 선택한다
- Gemini API에 이미지를 전송해 약 이름·용량·복용 횟수·복용 기간을 추출한다
- 인식 결과를 사용자가 확인·수정할 수 있다

### F-02. 복용 스케줄 생성
- AI 인식 결과를 기반으로 1일 복용 횟수·시간을 자동 설정한다
- 사용자가 알림 시간을 직접 조정할 수 있다

### F-03. 복용 알림 (로컬 알림)
- 설정된 시간에 기기 로컬 알림을 전송한다 (인터넷 불필요)
- 알림에서 바로 "복용 완료" 처리를 할 수 있다

### F-04. 복용 기록 관리
- 날짜별 복용 여부를 달력 뷰로 확인한다
- 복용률(%) 통계를 제공한다

### F-05. 약 정보 & 주의사항 요약
- Gemini API가 해당 약의 주요 주의사항과 부작용을 3줄 이내로 요약한다

## 5. 비기능 요구사항

| 항목 | 기준 |
|------|------|
| AI 응답 시간 | 스캔 후 인식 결과 표시까지 5초 이내 |
| 오프라인 동작 | 기등록된 알림은 오프라인에서도 동작 |
| 지원 플랫폼 | Android (최소), iOS (선택) |
| 데이터 저장 | 모든 데이터는 기기 로컬(SQLite)에만 저장 |
| 데이터 보안 | 약 사진은 API 전송 후 로컬 저장 안 함 |

## 6. 범위 외 (Out of Scope, MVP 기준)

- 약 재고 알림 (약이 몇 알 남았는지 추적)
- 병원·약국 연동
- 다중 사용자 공유

## 7. 성공 지표

- 약 스캔 → 스케줄 생성까지 전체 흐름이 데모에서 끊김 없이 작동
- 최소 3종의 다른 약 포장지로 AI 인식 성공률 80% 이상
