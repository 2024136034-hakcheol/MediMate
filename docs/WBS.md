# WBS & 일정표 — MediMate

## WBS (Work Breakdown Structure)

### 1. 기획 & 설계
- 1.1 주제 선정 및 팀 구성
- 1.2 PRD 작성 (기능 요구사항 정의)
- 1.3 아키텍처 설계 및 ADR 작성
- 1.4 화면 흐름도 작성

### 2. 환경 구축
- 2.1 Flutter SDK 설치 및 개발 환경 설정
- 2.2 GitHub 리포지토리 생성 및 브랜치 전략 수립
- 2.3 Gemini API 키 발급 및 연동 테스트
- 2.4 sqflite DB 스키마 설계

### 3. 구현 1 (핵심 기능 — 프로토타입)
- 3.1 카메라/갤러리 이미지 선택 기능
- 3.2 Gemini API 연동 (약 정보 추출)
- 3.3 인식 결과 확인·수정 화면
- 3.4 복용 스케줄 생성 및 로컬 DB 저장

### 4. 구현 2 (부가 기능 — 완성)
- 4.1 로컬 알림 (flutter_local_notifications) 구현
- 4.2 복용 기록 달력 뷰
- 4.3 복용률 통계 화면
- 4.4 약 주의사항 AI 요약 화면

### 5. 테스트 & 디버깅
- 5.1 다양한 약 포장지로 AI 인식 정확도 테스트
- 5.2 알림 동작 테스트 (오프라인 포함)
- 5.3 UI/UX 개선 및 버그 수정

### 6. 배포 & 문서화
- 6.1 Android APK 빌드
- 6.2 README, AGENTS.md 최종 정리
- 6.3 발표 자료 준비
