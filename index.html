Problem

문제 정의

약을 처방받고도 제대로 복용하지 못하는 세 가지 이유

01

입력이 귀찮다

약 이름·용량·복용 시간을 모두 손으로 직접 입력해야 해서, 시작 단계에서부터 진입 장벽이 생긴다.

02

잊어버린다

바쁜 일상 속에서 정해진 복용 시간을 자주 놓치고, 며칠 지나면 복용 자체를 중단하게 된다.

03

주의사항을 모른다

약 봉투에 적힌 주의사항·부작용 안내 텍스트를 꼼꼼히 읽지 않아 위험을 인지하지 못한다.

기존 약 복용 관리 앱들의 공통적인 한계 — "초기 설정이 너무 번거로워 결국 아무도 쓰지 않는다"

How to use

사용 방법

처음 약을 등록하고 복용 알림을 받기까지, 5단계면 충분합니다

01홈 화면에서 '약 추가' 버튼 탭
02카메라로 약 포장지 사진 촬영 (카메라 스캔)
03AI가 인식한 약 이름·용량·주의사항 확인 후 저장
04자동 생성된 복용 스케줄 확인
05알림 수신 시 '복용 완료' 체크
Tip — 약 정보나 복용 시간을 수정하고 싶다면, 홈 화면의 약 카드를 눌러 언제든 편집할 수 있습니다.

Architecture

시스템 구조

백엔드 서버 없이 동작하는 완전 로컬 구조 — 인터넷 연결은 AI 호출 시점에만 필요

graph LR A[사용자] --> B[Flutter UI] B --> C[GeminiService] B --> D[DbService] B --> E[로컬 알림] C --> F[Gemini API] D --> G[SQLite]
설계 포인트 — 서버 인프라 비용 없이 동작하며, 사용자 데이터는 기기 내부(SQLite)에만 저장되어 개인정보 처리 부담이 적다.

Scenario

사용자 시나리오

병원에서 감기약 3종을 처방받은 직장인의 첫째 날

기존 방식

  • 약 봉투를 꺼내 약 이름 확인
  • 앱에 약 이름을 직접 입력
  • 용량·복용 시간을 다시 입력
  • 입력이 번거로워 중도 포기
  • 결국 첫날 저녁 복용을 잊어버림

MediMate 사용 시

  • 약 포장 사진을 한 장 촬영
  • AI가 약 정보를 자동으로 인식
  • 복용 스케줄이 자동으로 생성됨
  • 알림이 자동으로 등록됨
  • 전체 설정 완료까지 약 30초
