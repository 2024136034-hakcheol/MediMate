# 01 — 요구사항

## 핵심 기능 (MVP)

### F-01. 약 스캔 & AI 인식
- 카메라 또는 갤러리에서 약 포장지 이미지를 선택한다
- Gemini API가 약 이름·용량·복용 횟수·복용 기간·복용 시점을 추출한다
- 사진 한 장에 약이 여러 종류 보이면 각각을 인식해 목록으로 보여주고, 항목별로 개별 등록할 수 있다 (다중 약 인식)
- 인식 결과를 사용자가 확인하고 수정할 수 있다

### F-02. 복용 스케줄 생성
- AI 인식 결과를 기반으로 1일 복용 횟수·시간을 자동 설정한다
- 사용자가 알림 시간을 직접 조정할 수 있다

### F-03. 복용 알림 (로컬 알림)
- 설정된 시간에 기기 로컬 알림을 전송한다 (인터넷 불필요)
- 알림에서 바로 "복용 완료" 처리를 할 수 있다

### F-04. 복용 기록 관리
- 날짜별 복용 여부를 달력 뷰로 확인한다
- 복용률(%) 통계를 제공한다

### F-05. 약 정보 & 주의사항 요약
- Gemini API가 해당 약의 주요 주의사항과 부작용을 3줄 이내로 요약한다

## 비기능 요구사항

| 항목 | 기준 |
|------|------|
| AI 응답 시간 | 스캔 후 인식 결과 표시까지 5초 이내 |
| 오프라인 동작 | 기등록된 알림은 오프라인에서도 동작 |
| 지원 플랫폼 | Android (최소), iOS (선택) |
| 데이터 저장 | 모든 데이터는 기기 로컬(SQLite)에만 저장 |
| 데이터 보안 | 약 사진은 API 전송 후 로컬 저장 안 함 |

## MVP 범위 외

- 약 재고 알림
- 병원·약국 연동
- 다중 사용자 공유
- 기기 간 동기화
