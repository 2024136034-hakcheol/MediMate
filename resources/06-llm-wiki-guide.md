# 본인 암묵지 운영 가이드 (LLM Wiki)

> 개발 중 알게 된 노하우를 기록해 다음 프로젝트에서 자산으로 활용

## 운영 위치

- **주 파일:** `AGENTS.md` 섹션 4 "암묵지 (LLM Wiki)"
- **형식:** 표 (상황 / 문제 / 해결책)

## 기록 기준

- AI가 생성한 코드에서 발생한 문제와 해결책
- 특정 패키지 사용 시 주의사항
- 프롬프트 패턴 중 효과적이었던 것 / 실패한 것
- Flutter/Dart 관련 트릭

## 현재 축적된 암묵지

| 상황 | 문제 | 해결책 |
|------|------|--------|
| Gemini API 이미지 전송 | base64 인코딩 방식이 패키지마다 다름 | dart:convert의 base64Encode 사용으로 통일 |
| JSON 파싱 오류 | API가 JSON 외 텍스트 포함 | 프롬프트에 "JSON만 출력" 명시 |
| Flutter 패키지 추가 | pubspec.yaml 버전 충돌로 빌드 오류 | 패키지 추가 전 pub.dev에서 최신 호환 버전 확인 |
| 로컬 알림 설정 | Android 권한 설정 누락으로 알림 미작동 | AndroidManifest.xml 권한 설정 체크리스트 작성 |
| Mermaid 렌더링 | 특수문자(✅, ·)가 Gantt 파싱 오류 유발 | 섹션명에 ASCII 외 특수문자 사용 금지 |

## 업데이트 방법

개발 중 문제를 해결할 때마다:
1. `AGENTS.md` 섹션 4 표에 행 추가
2. 커밋 메시지: `학철: LLM Wiki 업데이트 - [문제 요약]`
