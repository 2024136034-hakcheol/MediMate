## 01. Cover — (0:00 ~ 0:15)
"안녕하세요. PillNova 문학철입니다. 오늘 발표할 프로젝트는 사진 한 장으로 약 복용 관리를 끝내는 앱, MediMate입니다. Flutter와 Gemini API를 기반으로 만들었습니다."

## 02. Agenda — (0:15 ~ 0:25)
"발표는 문제 정의, 비전과 해결책, 사용 방법, 진행 현황, 아키텍처, 사용자 시나리오, 마지막으로 최종 결과 순서로 진행하겠습니다."

## 03. 문제 정의 — (0:25 ~ 0:55)
"약을 처방받고도 제대로 복용하지 못하는 이유는 크게 세 가지입니다. 첫째, 약 이름과 용량, 복용 시간을 일일이 손으로 입력해야 해서 처음부터 진입 장벽이 높습니다. 둘째, 바쁜 일상 속에서 정해진 시간을 자주 놓치고 결국 복용을 중단하게 됩니다. 셋째, 약 봉투에 적힌 주의사항을 꼼꼼히 읽지 않아 위험을 인지하지 못합니다. 결국 기존 약 복용 관리 앱들의 공통적인 한계는, 초기 설정이 너무 번거로워서 결국 아무도 쓰지 않는다는 점입니다."

## 04. 비전 & 해결책 — (0:55 ~ 1:25)
"MediMate의 해결책은 한 문장으로 요약됩니다. 카메라로 찍기만 하면, 나머지는 AI가 알아서 처리한다는 것입니다. 사용자가 약 포장지를 사진으로 촬영하면, Gemini API가 약 이름과 용량, 복용법, 주의사항을 자동으로 추출합니다. 이 정보를 바탕으로 복용 스케줄이 자동으로 생성되고, 정해진 시간에 로컬 알림이 발송됩니다. 이 전체 과정은 Flutter, Gemini API, SQLite, 로컬 알림만으로 동작하기 때문에, 서버 인프라 비용 없이 완전 무료로 운영할 수 있습니다."

## 05. 사용 방법 — (1:25 ~ 1:55)
"실제 사용 흐름은 5단계입니다. 홈 화면에서 '약 추가' 버튼을 누르고, 카메라로 약 포장지를 촬영합니다. AI가 인식한 약 이름, 용량, 주의사항을 확인하고 저장하면 복용 스케줄이 자동으로 생성됩니다. 이후 알림을 받을 때마다 '복용 완료'를 체크하면 됩니다. 그럼 실제 동작을 짧게 보여드리겠습니다."

## [데모] — (1:55 ~ 2:25, 30초)
시연 순서:
1. 홈 화면 확인
2. '약 추가' → 카메라(또는 갤러리)로 약 포장지 스캔
3. AI 인식 결과 확인
4. 복용 스케줄 자동 생성 확인

시연 중 멘트:
"이렇게 사진 한 장만 찍으면, 약 이름부터 복용 스케줄까지 자동으로 등록됩니다."

> 네트워크 문제로 데모가 안 될 경우를 대비해 30초 데모 영상 백업을 준비한다. (resources/10-demo-checklist.md 참고)

## 06. 진행 현황 (WBS) — (2:25 ~ 2:55)
"진행 현황입니다. 10주차 기획부터 시작해서, 11주차 설계와 환경 구축, 12주차 핵심 기능 구현과 중간발표, 13주차 알림·달력·통계 기능 완성, 그리고 14주차인 이번 주에는 단위·통합 테스트 작성, 코드 정적 분석, 이미지 압축을 통한 성능 최적화, Android APK 빌드, 문서 정리까지 모두 계획대로 완료했습니다. 이제 15주차 최종 발표만 남은 상태입니다."

## 07. 아키텍처 — (2:55 ~ 3:30)
"시스템 구조는 단순합니다. 사용자는 Flutter UI로 앱을 사용하고, UI는 두 가지 핵심 서비스와 통신합니다. GeminiService는 약 이미지를 Gemini API에 전송해 정보를 추출하고, DbService는 기기 내부 SQLite에 약 정보와 복용 기록을 저장합니다. 알림은 flutter_local_notifications로 로컬에서 처리됩니다. 즉, 백엔드 서버 없이 동작하는 완전 로컬 구조이며, 인터넷 연결은 AI 호출 시점에만 필요합니다. 이 설계 덕분에 서버 인프라 비용이 들지 않고, 사용자 데이터는 기기 내부에만 저장되어 개인정보 처리 부담도 적습니다."

## 08. 사용자 시나리오 — (3:30 ~ 4:00)
"병원에서 감기약 3종을 처방받은 직장인을 예로 들어보겠습니다. 기존 방식이라면 약 봉투를 꺼내 이름을 확인하고, 앱에 약 이름과 용량, 복용 시간을 일일이 입력해야 합니다. 이 과정이 번거로워 중도에 포기하고, 결국 첫날 저녁 복용을 잊어버립니다. MediMate를 사용하면 약 포장 사진을 한 장 촬영하는 것으로 끝입니다. AI가 약 정보를 자동으로 인식하고, 복용 스케줄과 알림이 자동으로 등록됩니다. 전체 설정 완료까지 약 30초면 충분합니다."

## 09. 최종 결과 & 마무리 — (4:00 ~ 4:30)
"최종 결과를 정리하면, 계획했던 presentation, domain, data 구조의 Flutter 프로젝트, Gemini API 기반 약 이미지 인식과 주의사항 요약, 카메라 스캔부터 복용 스케줄 자동 생성까지의 핵심 흐름, 로컬 알림과 복용 기록 달력, 통계 기능까지 모두 구현을 완료했습니다. 여기에 단위·통합 테스트 작성과 flutter analyze 통과, Android APK 빌드, 문서 정리까지 마쳤습니다. '촬영 한 번으로 끝나는 경험'이라는 비전을 실제 동작하는 앱으로 구현했고, 서버 비용 없이 완전 무료로 운영 가능한 구조까지 마무리했습니다."

## 10. Closing — (4:30 ~)
"여기까지 MediMate 최종 발표였습니다. 질문과 피드백 부탁드립니다. 감사합니다."
